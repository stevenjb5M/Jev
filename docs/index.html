How the race works

Both racers get the same tickets, the same four teams and the same descriptions. Calls run one at a time so we measure how long a single answer takes, and each racer gets one untimed warm-up call.

Jev @typesafe-ai/sdk

// Ask a typed question, get a label back
await client.systemOne({
  state: ticket.text,
  questions: {
    team: choice("Which team…?", {
      billing, technical, shipping, account,
    }),
  },
});
// → { choice: "billing", confidence: 0.97 }

Claude @anthropic-ai/sdk

// Prompt it, and force one of four labels
await client.beta.messages.create({
  model: "claude-opus-5-5",
  system: "Which team…? billing: …",
  messages: [{ role: "user", content: ticket.text }],
  output_config: {
    effort: "low",
    format: { type: "json_schema", schema },
  },
});
// → {"team": "billing"}
